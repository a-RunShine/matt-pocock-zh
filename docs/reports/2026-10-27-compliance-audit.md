- 位置：`中文版本/engineering/code-review/SKILL.md:3`
- 现状：

```

```

- 上游做法：`engineering/code-review/SKILL.md:3` 中内部引号写为转义形式 `\"review since X\"`：

```
description: "Review the changes since a fixed point (...) ... or asks to \"review since X\"."
```

- 证据（PyYAML 6.0.3 解析该 frontmatter）：

```
while parsing a block mapping
  in "<unicode string>", line 1, column 1:

    ^

  in "<unicode string>", line 2, column 159:
    ... 或提出"自 X 以来的评审"时使用。"
                                  ^
```

- 影响：38 个 `SKILL.md` 中**唯一**一个 frontmatter 无法解析的文件。`name` / `description` 是否被宿主读到取决于加载器的容错程度，最坏情况下整个 skill 不可被调用或描述为空。其余 37 个文件 YAML 解析全部通过。
