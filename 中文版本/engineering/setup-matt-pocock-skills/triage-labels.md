# 分诊标签

这些 skill 使用五个规范的分诊角色来描述。本文件把这些角色映射到本仓库 issue tracker 中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库 tracker 中的标签 | 含义                                     |
| -------------------------- | ----------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`          | 维护者需要评估此 issue                   |
| `needs-info`               | `needs-info`            | 等待报告者提供更多信息                   |
| `ready-for-agent`          | `ready-for-agent`       | 规格完整，可交给无人值守的智能体         |
| `ready-for-human`          | `ready-for-human`       | 需要人工实现                             |
| `wontfix`                  | `wontfix`               | 不会处理                                 |

当某个 skill 提到某个角色时（例如"应用 AFK 就绪的分诊标签"），使用本表中对应的标签字符串。

请编辑"本仓库 tracker 中的标签"一列，使之与你实际使用的词汇保持一致。
