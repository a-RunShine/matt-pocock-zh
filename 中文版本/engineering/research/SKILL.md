---
name: research
description: 依据高可信的一手来源调查一个问题，并将结论以 Markdown 文件的形式保存在仓库中。当用户希望对某个主题进行研究、收集文档或 API 事实，或将阅读类工作委派给后台智能体时使用。
---

启动一个**后台智能体**来完成研究，这样你可以在它阅读时继续工作。

它的工作是：

1. 依据**一手来源**（官方文档、源代码、规范、第一方 API）调查问题，而不是依据对它们的二手解读。追溯每项论断，找到拥有该事实的源头。
2. 将结论写入单个 Markdown 文件，并为每项论断注明其来源。
3. 将文件保存在仓库中已有此类笔记的位置；遵循现有约定。如果没有现成约定，则放在一个合理的位置，并说明放在了哪里。
