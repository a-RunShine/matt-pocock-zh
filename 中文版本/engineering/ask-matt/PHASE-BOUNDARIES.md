# 阶段边界

**阶段**是会话中的一块工作：拷问、实现、QA。这个定义是刻意模糊的：当你觉得"好了，这部分完成了"时，阶段就结束了。

**阶段边界**是两个阶段之间的间隙，也是这一决定唯一应当放置的地方。阶段中途没有决定要做：要么继续，要么把剩下的工作拆分给子智能体。在阶段中途压缩上下文，会让智能体丢失思路。

## 五个选项

| 选项           | 作用                                                                |
| -------------- | ------------------------------------------------------------------- |
| **继续**       | 留在会话中。完全没有上下文切换。                                    |
| **`/clear`**   | 清空上下文窗口，从零开始。                                          |
| **`/handoff`** | 写出一个可移植的 markdown 文件，并用它在任何地方为新会话提供种子。 |
| **子智能体**   | 把任务发送到它自己的上下文窗口，并取回一份报告。                    |
| **`/compact`** | 压缩当前上下文，并用摘要为新会话提供种子。                          |

## 决策树

在边界处自上而下依次判断。第一个**是**即胜出。

**1. 能否在本会话中继续？** 有两件事使答案为是：下一阶段需要把本阶段作为**一手来源**，或者你还剩下足够的 [smart zone（智能区）](https://www.aihero.dev/ai-coding-dictionary/smart-zone)（约 150k token）供下一阶段容纳。拷问 → 实现是标准的"是"：实现需要的是推理的原文，而不是它的摘要。继续既不花费任何代价，也不丢失任何东西，因此先把它定下来，再考虑其余选项。

**2. 当前上下文与接下来要做的事是否无关？** 本会话中的一切（探索、决定、死胡同）是否都可以丢弃？如果是，就用 **`/clear`**。它是棋盘上成本最低的一步：不花时间，并交还整个窗口。`/clear` 也并非终点：旧会话仍然可以恢复。

出错的代价是单向的。清除了一个*相关*的上下文，你就丢掉了所构建之物背后的**为什么**，而无论再怎么回读 diff，都无法找回。

**3. 是否需要交接？** `/handoff` 的范围很窄。只有在以下情况下才需要它：

- 切换到**新的 harness**（Claude → Codex），
- 迁移到**新的目录**或仓库，
- 把工作交给**同事**，
- 或在阶段中途发现了一个旁支任务，需要分叉出去而又不打乱你正在做的事。

这份清单就是全部条款。`/handoff` 换来的是**可移植性**：一个可以随身携带的文件。如果没有任何东西需要携带，你就不需要它。

**4. 该任务能否在无人值守（AFK）的情况下完成？** 任务的范围是否足够紧，可以在你离开键盘、无需指导的情况下运行？如果可以，就把它发给**子智能体**，并让本会话保持不动。自动化评审是标准情形：智能体读取 diff 并报告，在它工作时不需要你。

**5. 否则，`/compact`。** 相关的上下文、同一个 harness、同一个目录，并且你需要保持在回路中：这就是决策树的落点，而且经常落在这里。给它一条指令（`/compact we're going to QA this area`），使摘要保留下一阶段所需的内容。

`/compact` 是**默认选项，而非首选**。它位于底部，因为它上面的四个问题都更便宜或更精确。人们一开始就跳到这里时，典型的失败模式是：一个全新的会话对某个决定自信地犯错，而那个决定在摘要中被压平了。

## 一手来源与二手来源

除了**继续**之外，每一种操作都会把**一手来源**变成**二手来源**：会话按其发生的样子，被替换成对它的摘要。这种取舍形状总是相同的：

| 来源                           | 信息 | 噪声 | 腾挪空间 |
| ------------------------------ | ---- | ---- | -------- |
| 一手（继续）                   | 完整 | 很多 | 很小     |
| 二手（`/compact`、`/handoff`） | 有损 | 较少 | 很大     |

这就是为什么第 1 个问题排在最前面。只有当停留的成本超过它所节省的成本时，你才需要承受有损的代价。

## 这些都是判断题

这些问题并不客观：每一个都带有品味的成分，同一个边界在两天里可能会有两种不同的走法。它的价值在于**按顺序**提出这些问题，并且是在边界处提问，而不是在工作进行到中途时。
