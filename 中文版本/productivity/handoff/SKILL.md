---
name: handoff
description: 将当前对话压缩为一份交接文档，供另一个智能体接手。
argument-hint: "下一次会话将用于做什么？"
disable-model-invocation: true
---

撰写一份交接文档，总结当前对话，使一个全新的智能体能够接续工作。将其保存到用户操作系统的临时目录中（优先 `$TMPDIR`，否则 `/tmp`；Windows 上为 `%TEMP%`），而不是当前工作区。

在文档中加入一个"建议的 skill"部分，列出下一个智能体应当调用 Skill 工具的 skill 名称。

不要重复其他产物（规格说明、计划、ADR、issue、提交、diff）中已经记录的内容。通过路径或 URL 引用它们。

脱敏任何敏感信息，例如 API 密钥、密码或个人可识别信息。

如果用户传入了参数，就把它视为下一次会话的重点描述，并据此调整文档内容。
