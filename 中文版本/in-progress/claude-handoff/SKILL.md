---
name: claude-handoff
description: 将当前对话交接给一个全新的后台智能体，让它立即接手工作。
argument-hint: "下一次会话将用于做什么？"
disable-model-invocation: true
---

撰写一份当前对话的交接摘要，使一个全新的智能体能够接续工作。把它保存到用户操作系统的临时目录中，然后启动一个后台智能体，并以该文件作为其提示词：`claude --bg --name "<descriptive name>" -- "$(cat <summary file>)"`。通过文件传递，可以避免 shell 执行摘要中的反引号或展开其中的 `$`。它在当前工作目录中启动，并立即返回；用户通过 `claude agents` 管理它。

务必传入 `-n`/`--name` 并给出描述性的名称（例如 `--name "Fix login bug"`）；它会设置任务列表、会话选择器和终端标题中显示的名称。

在摘要中加入一个"建议的 skill"部分，列出下一个智能体应当调用 Skill 工具的 skill 名称。

不要重复其他产物（规格说明、计划、ADR、issue、提交、diff）中已经记录的内容。通过路径或 URL 引用它们。

脱敏任何敏感信息，例如 API 密钥、密码或个人可识别信息，因为该摘要会成为智能体的提示词。

如果用户传入了参数，就把它视为下一次会话的重点描述，并据此调整摘要内容。
