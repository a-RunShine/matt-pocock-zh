# 杂项（Misc）

我留着但很少用的工具，不在插件中推广。

- **[git-guardrails-claude-code](./git-guardrails-claude-code/SKILL.md)**：设置 Claude Code 钩子，在危险的 git 命令（push、reset --hard、clean 等）执行之前将其拦截。
- **[migrate-to-shoehorn](./migrate-to-shoehorn/SKILL.md)**：把测试文件从 `as` 类型断言迁移到 @total-typescript/shoehorn。
- **[scaffold-exercises](./scaffold-exercises/SKILL.md)**：创建包含章节、题目、答案和讲解的练习目录结构。
- **[setup-pre-commit](./setup-pre-commit/SKILL.md)**：用 lint-staged、Prettier、类型检查和测试设置 Husky 预提交钩子。
